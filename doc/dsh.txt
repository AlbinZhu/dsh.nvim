*dsh.txt*	在 Neovim 中调用 DeepSeek Harness (dsh)

==============================================================================
1. 简介							*dsh-intro*

dsh.nvim 是一个轻量插件，把 DeepSeek Harness (`dsh`) 接进 Neovim：

- 一次性任务模式：`dsh --profile headless "任务"`，结果显示在浮窗中。
- 交互式终端 TUI：把 dsh-tianshu-tui（`dsh --profile tui`）跑进 Neovim
  内置 `:terminal`，支持 float / split / vsplit / tab 布局并可 toggle。

要求：
- Neovim >= 0.10（依赖 vim.system / vim.fs）
- 可用的 `dsh` CLI（@deepseek-ai/dsh）
- （使用 TUI 时）已把 @huiliyi37/dsh-tianshu-tui 装进 tui profile

==============================================================================
2. 命令							*dsh-commands*

:Dsh [问题]					*dsh-:Dsh*
	向 dsh 提问。不带参数时弹出输入框。

:DshFile					*dsh-:DshFile*
	让 dsh 审查当前缓冲区关联的文件（小文件会内联进提示词）。

:'<,'>DshSelection				*dsh-:DshSelection*
	让 dsh 处理刚选中的文本（在 visual 模式下选中后调用）。

:DshCancel					*dsh-:DshCancel*
	取消正在运行的任务并关闭浮窗。

:dsh-tianshu-tui 终端集成~

:DshTui [文本]					*dsh-:DshTui*
	打开/收起 TUI（默认布局）。带参数时把文本输入到 TUI 输入行。

:DshTuiFloat					*dsh-:DshTuiFloat*
	在浮动窗口打开 TUI。

:DshTuiSplit					*dsh-:DshTuiSplit*
	在水平分屏打开 TUI。

:DshTuiVSplit					*dsh-:DshTuiVSplit*
	在垂直分屏打开 TUI。

:DshTuiTab					*dsh-:DshTuiTab*
	在新标签页打开 TUI。

:DshTuiClose					*dsh-:DshTuiClose*
	关闭/收起 TUI 窗口（进程后台继续运行）。

:DshTuiFile [路径]					*dsh-:DshTuiFile*
	把文件加进 TUI 输入行：默认以 `@"路径"` @mention 引用（提交时展开为摘要），
	`tui.file_mode = "content"` 时粘贴完整内容。不带参数时用当前缓冲区文件。

:'<,'>DshTuiSelection				*dsh-:DshTuiSelection*
	把 visual 选中的代码粘贴进 TUI 输入行（bracketed paste，不自动回车）。

:DshTuiInstall					*dsh-:DshTuiInstall*
	运行 `dsh plugin --profile tui add @huiliyi37/dsh-tianshu-tui` 安装 TUI。

3. 配置							*dsh-config*

	lua << EOF
	require("dsh").setup({
	  dsh_cmd = nil,            -- dsh 路径；nil 自动探测
	  profile = "headless",
	  cwd = "root",             -- "root" | "buffer" | "cwd" | 绝对路径
	  timeout_ms = nil,         -- 任务超时（毫秒）
	  include_file_content = true,
	  max_inline_file_chars = 20000,
	  close_key = "q",
	  keymaps = {
	    ask = "<leader>da",
	    ask_file = "<leader>df",
	    ask_visual = "<leader>ds",
	    tui = "<leader>tt",
	    tui_file = "<leader>tf",
	    tui_visual = "<leader>ts",
	  },
	  tui = {
	    profile = "tui",
	    launcher_args = {},
	    cwd = "root",          -- "root" | "buffer" | "cwd" | 绝对路径
	    layout = "split",      -- "float" | "split" | "vsplit" | "tab"
	    close_key = "q",       -- 终端 normal 模式下关闭/收起窗口
	    file_mode = "mention", -- "mention"(引用) | "content"(粘贴全文)
	    skip_update = false,   -- true = 跳过 npm 版本检查
	    float = {
	      relative = "editor", width = 0.94, height = 0.9,
	      row = 0.03, col = 0.03, anchor = "NW",
	      border = "rounded", title = " dsh-tianshu-tui ",
	      title_pos = "center", style = "minimal", focusable = true,
	    },
	    split = { position = "below", size = 0.4 },
	    vsplit = { position = "right", size = 0.5 },
	  },
	})
	EOF

未调用 setup() 时，命令也能工作（使用默认配置），只是不注册按键映射。

TUI 终端内的按键：`<C-\><C-n>` 进入终端 normal 模式，然后按 `q` / `<Esc>`
关闭/收起窗口。TUI 自身的快捷键（如 `Ctrl+Q` 退出）在终端 job 模式下直接可用。

==============================================================================
4. Lua API						*dsh-api*

	require("dsh").setup(opts)	配置并注册按键映射
	require("dsh").run(task)	运行任务
	require("dsh").ask(prompt?)	提问（无参数时弹出输入框）
	require("dsh").ask_file()	审查当前文件
	require("dsh").ask_visual()	处理视觉选择
	require("dsh").cancel()		取消任务
	require("dsh").open_tui(opts?)	打开/聚焦 TUI
	require("dsh").close_tui()	收起/关闭 TUI 窗口
	require("dsh").toggle_tui(opts?)	toggle TUI
	require("dsh").tui_install()	安装 TUI 插件到 tui profile
	require("dsh").tui_add_file(path?)	向 TUI 添加文件
	require("dsh").tui_add_selection()	把选区粘贴进 TUI
	require("dsh").tui_paste(text)	安全粘贴文本（bracketed paste）
	require("dsh.tui").send(text)	向 TUI 输入行发送文本

==============================================================================
5. 备注							*dsh-notes*

- headless 模式只输出最后一条回复，没有增量流式输出；运行期间浮窗会显示 spinner。
- 首次使用 headless profile 会自动初始化（首次运行略慢）。
- 如果 dsh 不在 PATH，可通过 `dsh_cmd` 指定绝对路径。

:dsh-tianshu-tui 备注~

- TUI 是全屏交互式终端应用，须先安装：
  `npx -y @deepseek-ai/dsh plugin --profile tui add @huiliyi37/dsh-tianshu-tui`
  或用 `:DshTuiInstall`。
- 首次使用 tui profile 会自动初始化（略慢）；之后每次启动会对照 npm 检查更新，
  不想联网检查时设 `tui.skip_update = true`。
- TUI 依赖 Node `^22.19 || >=24` 与 PATH 上的 `pnpm`。
