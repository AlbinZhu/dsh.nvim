*dsh.txt*	在 Neovim 中调用 DeepSeek Harness (dsh)

==============================================================================
1. 简介							*dsh-intro*

dsh.nvim 是一个轻量插件，把 DeepSeek Harness (`dsh`) 接进 Neovim：

- 交互式终端 TUI：把 dsh-TUI（`dsh --profile dsh-tui`）跑进 Neovim
  内置 `:terminal`，支持 float / split / vsplit / tab 布局并可 toggle。

要求：
- Neovim >= 0.10（依赖 vim.system / vim.fs）
- 可用的 `dsh` CLI（@deepseek-ai/dsh）
- （使用 TUI 时）已把 @deepseek-harness-tui/dsh-tui 装进 dsh-tui profile

==============================================================================
2. 命令							*dsh-commands*

:dsh-TUI 终端集成~

:DshTui [文本]					*dsh-:DshTui*
	打开/收起 TUI（默认布局）。带参数时把文本输入到 TUI 输入行。

:DshTuiFloat					*dsh-:DshTuiFloat*
	在浮动窗口打开 TUI。

:DshTuiSplit					*dsh-:DshTuiSplit*
	在水平分屏打开 TUI。

:DshTuiVSplit					*dsh-:DshTuiVSplit*
	在垂直分屏打开 TUI。

:DshTuiTab					*dsh-:DshTuiTab*
	在新标签页打开 TUI。

:DshTuiClose					*dsh-:DshTuiClose*
	关闭/收起 TUI 窗口（进程后台继续运行）。

:DshTuiFocus					*dsh-:DshTuiFocus*
	智能聚焦：光标已在 TUI 窗口里则收起（进程后台继续运行）；TUI 可见但光标在别处则
	聚焦；已收起或还没启动则打开并聚焦。对应 claudecode.nvim 的 :ClaudeCodeFocus。

:DshTuiResume [id]				*dsh-:DshTuiResume*
	以 `--resume [id]` 启动 TUI；不给 id 就恢复上一次会话（在 dsh-TUI 里 `--resume`、
	`-c`、`--continue` 含义相同）。该参数只在启动新进程时生效：TUI 已在运行（哪怕窗口
	已收起）时只把它显示出来，并提示在 TUI 里用 `/resume` 选择会话。

:DshTuiFile [路径] [起始行] [结束行]					*dsh-:DshTuiFile*
	把文件加进 TUI 输入行：默认以 `@"路径"` @mention 引用（提交时由 dsh-TUI 展开为附件），
	`tui.file_mode = "content"` 时粘贴完整内容。给出行号时只引用/粘贴这一段，引用写作
	`@"路径"#L12-14`。路径支持 `%`；不带参数时用当前缓冲区文件。
	引用里的路径：文件位于 TUI 工作目录之下时写成相对路径，否则写绝对路径。

:'<,'>DshTuiSelection				*dsh-:DshTuiSelection*
	把 visual 选区加进 TUI 输入行（不自动回车）。默认只在输入框里显示文件名和行号
	`@"路径"#L起-止`（像 claudecode.nvim），不粘贴代码；缓冲区没有文件、文件还没写到磁盘
	或有未保存的修改时，会退回成粘贴代码（bracketed paste）。`tui.selection_mode = "content"`
	则总是粘贴代码。
	在文件树里则添加选中的文件。

:DshTuiTreeAdd					*dsh-:DshTuiTreeAdd*
	在文件树里把光标下的文件/目录（或 `:'<,'>` 选中的行）加进 TUI 输入行，始终是
	@mention。支持 nvim-tree、neo-tree、oil.nvim、mini.files、netrw，以及 snacks 的
	explorer / picker 列表；多选方式见 |dsh-notes|。

3. 配置							*dsh-config*

	lua << EOF
	require("dsh").setup({
	  dsh_cmd = nil,            -- dsh 路径；nil 自动探测
	  keymaps = {
	    tui = "<leader>tt",
	    tui_file = "<leader>tf",
	    tui_visual = "<leader>ts",  -- 选中代码；在文件树里则是选中的文件
	    tui_focus = "<leader>tF",   -- 智能聚焦 / 收起
	    tui_resume = "<leader>tr",  -- 恢复上一次会话
	    tui_tree = "<leader>ts",    -- 文件树里：添加光标下的文件（buffer-local）
	  },
	  tui = {
	    profile = "dsh-tui",
	    launcher_args = {},
	    cwd = "root",          -- "root" | "buffer" | "cwd" | 绝对路径
	    layout = "vsplit",     -- "float" | "split" | "vsplit" | "tab"
	    close_key = "q",       -- 终端 normal 模式下关闭/收起窗口
	    file_mode = "mention", -- "mention"(引用) | "content"(粘贴全文)
	    selection_mode = "mention", -- "mention"(引用 @文件#L起-止；缓冲区不可靠时粘贴代码) | "content"(总是粘贴)
	    auto_insert = true,    -- 窗口获得焦点后自动进入终端模式（包括 Ctrl+hjkl 移动回来）
	    provider = "auto",     -- "auto"(装了 snacks.nvim 就用它) | "snacks" | "native"；tab 布局始终用原生
	    window_nav = { h = true, j = true, k = true, l = true }, -- 终端里 <C-h/j/k/l>；false 全关，单个方向设 false 只关它
	    float = {
	      relative = "editor", width = 0.94, height = 0.9,
	      row = 0.03, col = 0.03, anchor = "NW",
	      border = "rounded", title = " dsh-tui ",
	      title_pos = "center", style = "minimal", focusable = true,
	    },
	    split = { position = "below", size = 0.4 },
	    vsplit = { position = "right", size = 0.3 }, -- size: 占编辑器宽度的比例
	  },
	})
	EOF

未调用 setup() 时，命令也能工作（使用默认配置），只是不注册按键映射。

打开或聚焦 TUI 后会直接进入终端模式，可以马上输入（`tui.auto_insert = false` 可关闭）。
从任何窗口切回 TUI 窗口时也会进入终端模式。
TUI 终端内，`<C-h>` / `<C-j>` / `<C-k>` / `<C-l>` 切到对应方向的窗口并退出终端输入模式，
和 claudecode.nvim 一样（`tui.window_nav` 可以单独关掉某个方向）。`<C-\><C-n>` 之后按
`q`（`tui.close_key`）也能收起窗口。其它按键（包括 `q` 和 `<Esc>`）都原样交给 TUI，
TUI 自身的快捷键（如 `Ctrl+B` 侧边栏）也直接可用。dsh-TUI 自己的 `Ctrl+J`（换行）、
`Ctrl+K`（删到行尾）和 `Ctrl+L`（重绘）在窗口导航开着时会被占用，需要的话把对应方向关掉。
终端输入模式下的 `<S-CR>`（Shift+Enter）在输入框里换行，不会提交。

4. Lua API						*dsh-api*

	require("dsh").setup(opts)	配置并注册按键映射
	require("dsh").open_tui(opts?)	打开/聚焦 TUI
	require("dsh").close_tui()	收起/关闭 TUI 窗口
	require("dsh").toggle_tui(opts?)	toggle TUI
	require("dsh").focus_tui(opts?)	智能聚焦/收起 TUI
	require("dsh").resume_tui(id?)	以 --resume [id] 启动 TUI
	require("dsh").tui_add_file(path?, start_line?, end_line?)	向 TUI 添加文件（可带行区间）
	require("dsh").tui_add_files(paths)	一次引用多个文件/目录
	require("dsh").tui_add_tree(range?)	把文件树里光标下/选中的文件加进 TUI
	require("dsh").tui_add_selection()	把选区加进 TUI（文件名+行号，或代码）
	require("dsh").tui_paste(text)	安全粘贴文本（bracketed paste）
	require("dsh.tui").send(text)	向 TUI 输入行发送文本

==============================================================================
5. 备注							*dsh-notes*

- 如果 dsh 不在 PATH，可通过 `dsh_cmd` 指定绝对路径。

:dsh-TUI 备注~

- TUI 窗口默认用 snacks.nvim 的终端（装了 snacks.nvim 时，`tui.provider = "auto"`），
  所以你给 snacks 终端配的按键也会生效；没装或设 `tui.provider = "native"` 时用 Neovim
  自带的终端。
- TUI 是全屏交互式终端应用，须先安装：
  `npx -y @deepseek-ai/dsh plugin --profile dsh-tui add @deepseek-harness-tui/dsh-tui`
  （首次安装要用 pnpm 拉依赖，会慢一些）。
- 启动后 dsh-TUI 会在后台检查更新，不会阻塞界面；在 TUI 里输入 `/update` 升级。
- TUI 依赖 Node `^22.19 || >=24` 与 PATH 上的 `pnpm`。
- 文件树多选：neo-tree、oil、mini.files 在 visual 模式选中多行；nvim-tree 用书签、netrw
  用 `mf` 标记、snacks 用 `<Tab>` 选中，再执行 |dsh-:DshTuiTreeAdd|。文件树里的添加始终是
  @mention，不受 `tui.file_mode` 影响。
- 选区默认（`tui.selection_mode = "mention"`）引用的是磁盘上的文件，所以缓冲区有未保存的
  修改、没有文件名、不是普通文件或文件还没写到磁盘时，会退回成粘贴代码。
- 与 claudecode.nvim 的对应关系见 README 的 "Coming from claudecode.nvim?" 一节。
